# Calculator-App
A clean responsive Calculator web app built with HTML, CSS, and JavaScript, supporting arithmetic operations and keyboard input.

✨ Features

* **Core Math Operations:** Addition (`+`), Subtraction (`-`), Multiplication (`×`), Division (`÷`), and Percentages (`%`).
* **Input Controls:** Clear entry (`C` / `AC`), Backspace / Delete (`DEL`), and decimal point handling.
* **Keyboard Support:** Complete keyboard integration — type numbers, operators, and press `Enter` to calculate or `Backspace` to delete.
* **Smart Input Handling:** Prevents duplicate operators, leading zeros, and division by zero crashes.
* **Responsive Layout:** CSS Grid and Flexbox layout that scales seamlessly on desktop, tablet, and mobile devices.
